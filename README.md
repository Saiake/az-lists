# az-lists

Списки доменов, IP и ASN для маршрутизации. Раздаются через GitHub Pages:

```
https://<user>.github.io/az-lists/<папка>/<файл>
```

## Папки

| Папка       | Что внутри | Кто меняет |
|-------------|------------|------------|
| `upstream/` | Редакция исходных списков: только то, что принято. | Только через PR. |
| `own/`      | Свои списки. | Руками. |

## Файлы

| Файл            | Что это | Куда |
|-----------------|---------|------|
| `world.txt`     | Домены | зарубежный выход |
| `local.txt`     | Домены | локальный выход |
| `exclude.txt`   | Домены напрямую, мимо VPN. Формат v2fly, поддерживает `include:` | — |
| `ips.txt`       | IP и подсети | локальный выход |
| `ips-world.txt` | IP и подсети | зарубежный выход |
| `asn.txt`       | ASN и организации | локальный выход |
| `asn-world.txt` | ASN и организации | зарубежный выход |
| `dns.txt`       | DoH-серверы, которые блокируются | только `upstream/` |
| `block.txt`     | Блокировка шпионских доменов | только `upstream/` |

Строки с `#` — комментарии.

## Изменения в `upstream/`

Изменения исходных списков приходят PR-ами. В PR попадает только новое со
времени прошлого PR.

- **Merge** — принять.
- **Правка файлов в PR** — принять частично или вернуть удалённую строку.
- **Close** — отклонить. Эти изменения больше не придут.

Исключение в `own/exclude.txt` убирает домен из **всех** источников. Правка в
PR убирает его только из `upstream/`.

## Не публиковать здесь

Репозиторий публичный. Не кладите сюда ничего личного: свои IP, адреса
серверов и домены, по которым можно узнать вас или ваших пользователей.
